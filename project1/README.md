# Project 1: JavaFX Login and Registration

This is my first project in JavaFX and part of my Java learning journey. The project focuses on building a simple Login and Registration interface and implementing navigation between the two pages.

## What I Have Learned

Through this project, I have gained practical experience with:

- **JavaFX Fundamentals:** Understanding how JavaFX works and how to build desktop applications.
- **UI Components:** Creating and working with interface elements such as Labels, TextFields, PasswordFields, Buttons, Hyperlinks, and Layout Containers.
- **Scene Builder:** Using JavaFX Scene Builder to visually design interfaces and manage FXML layouts.
- **FXML:** Creating and managing application interfaces using FXML.
- **Event Handling:** Using Action Events to handle user interactions, such as button clicks and hyperlink actions.
- **Page Navigation:** Linking different pages (Login and Registration) and switching between scenes using JavaFX.
- **Controllers:** Connecting FXML components to Java controller classes using `@FXML`.

## Technologies Used

- Java 21
- JavaFX
- FXML
- JavaFX Scene Builder
- IntelliJ IDEA
- Maven

## Project Goals

The goal of this project is to strengthen my understanding of Java programming, JavaFX GUI development, event handling, and building interactive desktop applications.

This is just the beginning of my JavaFX learning journey, and I look forward to building more projects and improving my skills.
